# 白話重寫與章頭尾銜接 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 將 `chapters/` 全 20 章重寫為敘事口語文風、補完章頭/章尾銜接，用 3 個並行 subagent（7/7/6 切分）完成，並通過 `verify_chapter.py` 與主 session 抽檢。

**Architecture:** 主 session 先落地風格指南（單一事實來源），再並行派 3 個 general subagent 各自按章序就地重寫一批；每章改完即 verify。主 session 收批後做全量 verify、銜接完整性檢查、跨批邊界對照與抽檢，必要時自行小修。

**Tech Stack:** opencode `task`（subagent_type=`general`，最多 3 個、可 resume）、`tools/verify_chapter.py`（以 `/home/piondeno/uvEnv/baseEnv` 執行）、git（僅回滾點，不 commit）。

**Spec:** `docs/superpowers/specs/2026-10-04-白話重寫與章頭尾銜接-design.md`

## 全域約束

- **同一時間最多 3 個 subagent**（使用者硬約束）；`task` 工具單則訊息發 3 個
- subagent 上下文不足時用 `task_id` **resume 同一個**；永不新增第 4 個
- 執行環境：`/home/piondeno/uvEnv/baseEnv`
- 就地改寫 `chapters/`；回滾點 = git HEAD（255c9d4）；**不 commit**（使用者未要求）
- `chapters (副本)/`、`chapters (其他副本)/`：不動
- subagent 只准改指派給它的章節檔
