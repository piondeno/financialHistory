# 全書術語替換：「投標」→ 分層映射（投機標的 / 押注 / 投機者）

## 背景與決策（使用者選定方案 B）

「投標」為全書主軸詞，共 270 處（ch01 2、ch10 1、ch12 34、ch13 56、ch14 9、ch15 15、ch16 13、ch17 19、ch18 26、ch19 26、ch20 69），另有 README 15、PLAIN-STYLE 5。
毛病：繁中「投標」≈ 招標投標（tender），讀者易誤解；唯一定義在 ch12 且自稱「本章」；ch02–ch09 完全不用；全書已混用「押注/下注/標的/投機標的」。

## 映射規則

| 原文 | 新文 | 說明 |
|---|---|---|
| 投標對象、投標標的、投機對象 | 投機標的 | 名詞層；與書名《金融投機史》同軸 |
| 投標者 | 投機者 | 既有詞，零註解成本 |
| 投標管道 | 投機管道 | 名詞層 |
| 投標（動詞：投標「X 會漲」、在投標、的投標） | 押注 | 動作層，保留口語語感 |
| 投標本質 | 投機標的本質 | 視上下文微調 |

特殊處理：
- ch13 §3.1 刪掉括注「（投標，此指「下注/賭注」）」
- ch12 章頭「本章以「投標」指「下注／賭注」」定義句改寫（不再需要自創詞定義）
- ch01 開場主軸句改用新詞，並在此定義（定義位置從 ch12 提前到全書開場）
- 避免「投機標的的擴散」「投機標的，是投機標的擴散路徑」這類重複，必要處順句
