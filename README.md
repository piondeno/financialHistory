# 金融投機史：1837–2026 的投機、危機與制度演變

20 章長書，每章獨立 markdown 檔，涵蓋 1837 年美國恐慌至 2026 年的金融投機、危機與制度演變。
每章 ≥2 萬字，結構：背景→興起→頂點→崩潰→後續→分析→評判。

[中央銀行的毀滅與長恐慌（1837–1847）](chapters/ch01-1837-1847-中央銀行的毀滅與長恐慌.md) — 1832 年傑克森否決第二合眾國銀行續約，其後四年以撤走聯邦存款、頒布金銀令，把這家事實上的國家央行逼成一家賓州私人公司——這是人類史上第一次大規模「拆毀央行」實驗，帳單隨之而來：1837 年紐約銀行停止兌付，1837 年恐慌撕開近七年衰退，逾四成銀行倒閉、各州競相違約、美國被逐出國際資金市場近十年。本章以「無央行時代」（1837–1863）為主線，解釋沒有「最後貸放人」的國家其危機形態：銀行搶存的自我強化、金本位的跨境傳導、棉花價格鏈。與此對照，英國 1844 年反向集中發鈔權，其 1847 年危機一週內平息——一邊無央行熬七年、一邊有央行一週復甦，構成金融史上關於央行存在價值最完整的自然實驗。
