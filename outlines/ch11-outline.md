# ch11 細綱（1948–1971 黃金年代與布雷頓森林崩解）

## 全章定位與主軸
- **定位**：接 ch10（戰後布雷頓森林建立、馬歇爾、德國 DM、柏林封鎖）。本章講這套體系在「黃金年代」**如何運作**、又因**特裡芬兩難**如何**崩解**，終至 1971 尼克松關金窗、1973 全面浮動。
- **主軸（投機對手方第四跳）**：ch08 個人投機者 → ch09 制度（聯準會/金本位）→ ch10 超級大國（戰時）→ **ch11：投機者變為「國家」——法、德、瑞士、英以美元向美政府兌金離岸，對美國黃金儲備發動挤提；而真正的「對手」是體系本身的結構性矛盾（特裡芬兩難）。**
- **兩頂峰**：①**1950s-60s 黃金年代**（供給＋制度雙豐收，史上最長和平繁榮）；②**1967-1971 崩解**（鎊→金→美元，骨牌倒完）。
- **核心論點**：固定匯率＋美元兌金的體系，其**穩定（供給流動性）必然侵蝕其信心（美元兌金）**，此矛盾無解——只能選「何時爆」。1971 是選擇的時刻。
- **前後指**：前指 ch10（布雷頓森林建立 1944、$35/oz、馬歇爾）；後指 ch12（1973 油危機、石油美元、1970s 停滯性通膨、Jamaica 1976）。
- **書體例**：繁體、U+2011=0、CR=0、無簡體；每節末標「（來源：Wikipedia『…』）」；§9 為「關鍵數據表＋定性註記＋參考來源」。

## 逐節要點與配額

### §1 導言：從戰時動員到布雷頓森林（~500 字）
- 承 ch10：1948 年戰債/復員/OPA 解除的經濟，接上 1944 布雷頓森林建立的貨幣秩序。
- 本章問題：這套「美元＝金、他幣＝美元」的固定制，撐了多久？為何必垮？
- 點出主軸：黃金年代的繁榮正是埋下崩解之因——美元要當世界貨幣，就必須外流，外流就侵蝕其兌金能力。
- 一語預警：1959 年美元已多過黃金 backing，1971 只是認帳。

### §2 布雷頓森林的運作：釘住、可兌換與自由貿易（1948–1957）（~4800 字）
- 2.1 體制的骨幹：44 國、$35/oz、±1% 帶、1958 全運作、bancor 落敗美元當儲備、美持 574M oz（世界半數以上）。
- 2.2 貿易自由化：GATT（1947 簽、九輪、關稅 22%→15%）、EPU（1950-58、多邊清算、貿易翻倍）、馬歇爾 $12B。
- 2.3 為何「管用」：戰後美元短缺（不是多餘）、歐洲重建需求旺、可兌換 1958 恢復；金融穩定（Wolf：27 年 38 次危機）。
- 2.4 隱憂埋線：美元外流是「功能」也是「病根」——為世界供給美元＝美國逆差＝黃金流出。
- 小結：制度的成功，正是其衰落的起點。

### §3 黃金年代：史上最長的和平繁榮（1950–1973）（~4800 字）
- 3.1 定義與時間（1950/51 起、1973 終）；OECD growth（1950s>4%、1960s~5%）；Maddison 各國成長表（日 9.29、德 5.68、法 5.05、美 3.93、英 2.93）。
- 3.2 美國：GDP $228B→$1.7T、五度衰退、戰債到期、GI Bill、工會頂峰、郊區化、中產階級擴張。
- 3.3 各國奇蹟：西德 Wirtschaftswunder（Erhard、DM 1948）、法國 Trente Glorieuses、日本（韓戰拉動）、英國「never had it so good」。
- 3.4 成因：生產力＋凱因斯主義＋州際公路（1956）＋軍費＋金融壓制＋財富再分配＋低油價＋國際合作。
- 3.5 投機者視角：這二十年「投機」的對象是實體（房、股、消費），而非匯率——固定匯率把貨幣投機壓到地底；但這恰是下一節要打破的。
- 小結：繁榮的另一面，是美元悄悄積累了過多的海外負債。

### §4 特裡芬兩難：儲備貨幣的原罪（1959–1961）（~3000 字）
- 4.1 兩難的表述：Triffin（1960s）、先聲（Młynarski 1929、Rueff 1932）、凱恩斯 bancor。
- 4.2 機制：供給流動性須逆差→美元高估→黃金流出；維護信心須順差——**逆差與順差不可並存**。
- 4.3 時序：1959 美元>金 backing、1960 秋金價 $40 vs $35、1961 金池＋GAB 上場。
- 4.4 數據：1966 非美持 $14B 美元 vs 美 $13.2B 金（可覆蓋僅 $3.2B）、1970 覆蓋率 55%→22%。
- 小結：這不是政策失誤，是**結構**——只要美元是世界貨幣，矛盾就在。

### §5 鎊的崩解：第一張倒下的骨牌（1949 與 1967）（~2400 字）
- 5.1 鎊的前史：1925 重行金本位、1931 放棄（貶 25%）。
- 5.2 **1949-09-19 貶 30.5% 至 $2.80**——戰後第一次大國貨幣崩，引發跟隨貶值；美國「過度特權」初顯（別國只能貶，美國不用）。
- 5.3 1961/64/66 鎊再受壓、1966 匯兌管制（£50 旅行支票）。
- 5.4 **1967-11-18 貶 14.3% 至 $2.40**——第二倒，且直接衝擊金市（鎊貶→賣鎊者轉攻美元/金）。
- 小結：鎊是最先暴露「固定制＋儲備貨幣」矛盾的——它既是釘住者，又缺金。

### §6 金價失控：金池瓦解與雙軌時代（1961–1968）（~3000 字）
- 6.1 金池（1961-11-01、八國）原理：逢高拋、回補，壓住 $35；金價因古巴飛彈危機等衝 $40。
- 6.2 支撐手段：1964 減稅、西德承諾不買金、GAB 貸款。
- 6.3 **1968-03 金池瓦解**：美元兌金擠提、先關英國銀行假日再關倫敦金市。
- 6.4 **雙軌制**：央行間 $35、私市自由（1968-03-18 廢 25% 金準備）；金價驟升 $43→1969 底回觸 $35→穩升→1972 >$70→1973-11 $100。
- 小結：官方價與市場價「兩張皮」，$35 已成口頭——市場已用腳投票。

### §7 尼克松衝擊：關掉金窗的那個星期日（1971）（~4000 字）
- 7.1 崩解序曲：1965 de Gaulle、1971-05 西德退出、08-09 瑞士退出、08-11 英取金（Volcker「局已盡」）。
- 7.2 臨界點：金僅 10,000 公噸（<峰值半）、失業 6.1%、通膨 5.84%。
- 7.3 **08-13 Camp David** 密會；**08-15（日，市場休市）** 三措施：關金窗、EO 11615 90 天凍結、10% 進口附加稅；演說「過去七年一年一危機」。
- 7.4 立即反應：Dow +33（當時史上最大單日）、日銀買 $1.3B 保 360 JPY、政治成功（1972 連任）。
- 7.5 **史密森協定（1971-12）**：$38/oz（貶 7.9%）、±2.25%、SDR 平衡。
- 7.6 **1973-02 再貶 10%、日/OEEC 轉浮動**→十國跟隨→**布雷頓森林 de facto 瓦解**；美元 1970s 跌三分之一。
- 小結：不是「崩潰」，是「認帳」——把雙軌的市場價正式化為唯一價。

### §8 投機者視角：國家是投機者，兩難無解（~2500 字）
- 8.1 本段投機者＝國家：法（de Gaulle/Pompidou 派船取金）、德、瑞士、英——以美元兌金離岸。
- 8.2 結構性套利：穩定＝流動性＝信心侵蝕，無解，只能選「何時爆」。
- 8.3 「過度特權」（Giscard）：Eichengreen「印 $100 幾美分，別國拿 $100 實貨換」。
- 8.4 終局與轉折：固定匯率時代結束→浮動時代（貨幣投機主體轉為央行/基金/企業）；前指 ch12（Jamaica 1976、石油美元、1973 油危機、1970s 停滯）。
- 8.5 總評：布雷頓森林證明——**用單一國家貨幣當世界錨，必然被該國的國內政策與赤字所拖累**；凱恩斯若採用 bancor 或許不同，但歷史沒那麼走。
