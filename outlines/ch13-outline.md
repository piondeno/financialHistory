# ch13 細綱（1979-1987 沃克抗通膨、1980s 狂熱與黑色星期一）

## 全章定位與主軸

- 承接 ch12（1979-08 Volcker 上任、1979-10 轉貨幣目標）。
- 主軸：投機標的從 ch12「**預期本身**」擴為**「槓桿本身」**與**「算法/程式交易」**——1980s 的投機，是押注「槓桿能撐多久」與「程式會怎麼反應」。
- 三段：沃克抗通膨（1979-82：利率 11.2%→prime 20.5%、雙頂衰退、失業 10.8%、通膨 14.8%→3%）／1980s 狂熱（1982-87：金融自由化、垃圾債 Milken、LBO 9:1、Reaganomics、Plaza 1985 美元貶/日圓升、泡沫化）／黑色星期一（1987-10-19：道指 -22.6%、全球 23 市、$1.7 兆、Greenspan 救火）。
- 收尾伏筆：Greenspan put（1987 誕生）、S&L 危機/日本泡沫/RJR Nabisco（留 ch14）。

## 逐節要點與配額

### §1 本章摘要（~600）
1979-10 轉貨幣目標→利率 11.2%→prime 20.5%（1981-08）→雙頂衰退 1980-82、失業 10.8%→通膨 14.8%（1980-03）→3%（1983 底）→1982-83 復甦＋金融自由化（DIDMCA/Garn-St Germain）→垃圾債（Milken）＋LBO（9:1 債務股本比）→Reaganomics（稅切 70%→28%、軍費 $267B→$393B、債務 $738B→$2.1T）→1985 Plaza（美元貶/日圓升、伏筆日本泡沫）→1986-87 泡沫化→1987-10-19 Black Monday（道指 -22.6%、全球 $1.7 兆、Greenspan 救火 $17B）。投機標的：槓桿＋算法＋央行反應。

### §2 歷史背景（~3400）：沃克抗通膨
- 2.1 1979-10 貨幣目標轉向（monetarist、federal funds 11.2% 起）
- 2.2 1980 第一次緊縮（federal funds 17.6%（1980-04）、1980-01~07 衰退、車貸/房貸信用縮）
- 2.3 1981-82 第二次衰退與利率頂（1981-07~1982-11、prime 20.5%（1981-08）、製造失 110 萬、汽車工失 24.7%、失業 10.8%（1982-11，1941 以來首次雙位數）、黑人 20%）
- 2.4 政治代價與復甦（農民駕拖車上 C Street、Reagan 1981 上任/ERTA、1982-11 結束、1983 復甦強於 1953 以來）

### §3 投機的興起（~3200）：1980s 狂熱
- 3.1 1982-83 通膨死、復甦起（通膨→個位數、利率降、但強美元壓製造、製造就業 -280 萬、去工業化）
- 3.2 金融自由化（DIDMCA 1980/Garn-St Germain 1982、利率上限除、證券化、S&L 危機伏筆）
- 3.3 垃圾債革命（Milken/Drexel、fallen angels、高 yield 違約率 ~5%）
- 3.4 LBO 狂潮（Kohlberg/Kravis 1960s 構想、1982 Gibson Greetings $80M→$290M、債務占 50-90%/>9:1、1984 Volcker/Shad 攻擊「債務倒金字塔」）

### §4 頂點與轉折（~2900）：泡沫化
- 4.1 強美元與保護主義（美元 1980-85 +50%、1985-03 對英鎊新高、逆差 3.5% GDP、製造/農推保護、Baker 1985-01 接任轉態度）
- 4.2 1985-09 Plaza Accord（Plaza Hotel 五國、"有序讓非美元升值"、週一美元 -4%、目的貶美元縮逆差）
- 4.3 Plaza 效應與日本伏筆（前兩年逆差惡化後降、對日未縮、日圓升→日本擴張→日本資產泡沫伏筆 ch14、1987-02 Louvre 止跌）
- 4.4 Reaganomics 頂與不平等（misery 19.33→9.72、S&P +113.3%、債務 $738B→$2.1T、赤字 5.7%、top 1% 9.0%→13.8%）

### §5 崩潰與危機（~3000）：黑色星期一
- 5.1 牛市與引爆（S&P 102.42→336.77/DJIA 776→2722、1987-10-14 稅改案+貿易逆差、周末 portfolio insurers 指示賣）
- 5.2 1987-10-19 Black Monday（道指 -508 點/-22.6%、S&P -20%、95 檔暫停、最後 90 分鐘）
- 5.3 流動性/保證金危機（margin call 10 倍、undersegregated、Mishkin「蔓延性倒閉」）
- 5.4 Greenspan 救火（10-20 声明、$17B 注入、>25% 準備、moral suasion、Bernanke 評）
- 5.5 全球蔓延（23 市、$1.7 兆、日 $421B/-14.9%、港 -45.8%/Guarantee Corp 崩、紐西蘭 -60%、S&P 谷底 230.30/-31.6%、1989-07-26 才恢復）

### §6 後續與制度變革（~2200）
- 6.1 Greenspan put 誕生（1987 救火＝央行「最後買方」先例、Greenspan 主政至 2006、影響 ch15-16）
- 6.2 Louvre Accord 與美元（1987-02 止美元跌、協調失效伏筆崩盤）
- 6.3 投機制度教訓（index arbitrage/de-linked、portfolio insurance 正回饋、全球恐慌傳導）
- 6.4 LBO/垃圾債退潮（Campeau/Revco 破產、Drexel nolo contendere、RJR Nabisco $31.1B 1989＝終點伏筆）

### §7 深度分析（~3000）
- 7.1 Volcker shock＝Great Moderation 起點（Stock/Watson 2002、央行獨立、用衰退換通錨/Taylor rule 雛形）
- 7.2 1980s＝槓桿化投機典範（垃圾債+LBO+去管制、頂重腳輕、押注「槓桿能撐多久」）
- 7.3 Black Monday＝投機標的從實體到算法（Shiller 889 訪、endogenous cascade/meltdown、二階預期/反身性、演算法投機原型）
- 7.4 強美元→日本泡沫傳導（Plaza→日圓升→日銀寬鬆→泡沫→失落十年）＋ Greenspan put＝央行角色投機化（最後貸放人→最後買方）

### §8 评判與評斷（~2400）
一、沃克抗通膨＝央行作為通膨殺手的典範（雙頂衰退代價 vs Great Moderation 回報）
二、1980s＝槓桿化投機典範（垃圾債+LBO、頂重腳輕注定 1989-91 清算）
三、1987＝演算法/程式投機原型（崩盤可由投機者的投機者的算法驅動、非基本面）
四、投機標的擴散路徑定位（金→股/鐵路→匯率/金→預期→**槓桿+算法+央行反應**→新興市場→網路/房→CDO）
